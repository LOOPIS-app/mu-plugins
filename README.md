# 🎯 LOOPIS mu-plugins
**Mini plugins loading from the folder 'mu-plugins' of LOOPIS.app**

## 💡 Status
Plugins placed here run early and cannot be deactivated by accident.

## 🖼️ Image uploads
JPEG, PNG, WebP, and supported HEIC/HEIF uploads are re-encoded before attachment creation; full-size files are capped at 1280px with quality set to 70, and HEIC/HEIF is converted to JPEG. WordPress generates only the configured thumbnail size (240×240 on LOOPIS sites), avoiding duplicate large and scaled files. Other formats use WordPress defaults.
